# Cybersecurity Portfolio

I’m building hands-on cybersecurity and infrastructure skills for entry-level SOC, blue-team, data-center, and security-support roles.

My focus is turning foundational knowledge into documented, repeatable labs that show how I approach systems, networking, automation, and security operations.

## Current learning focus

- **SOC and blue-team fundamentals:** alert triage, log analysis, incident response, and detection concepts
- **Networking:** TCP/IP, DNS, DHCP, ports, packet analysis, and network troubleshooting
- **Endpoint security:** Windows and Linux administration, logging, and hardening
- **Automation:** PowerShell and Python for repeatable administrative and security tasks
- **Homelab infrastructure:** virtualization, segmented lab networks, and service deployment
- **Certification domains:** reinforcing Security+ and Network+ concepts through hands-on practice

## Documentation approach

Each security project will aim to include:

1. The problem or skill being practiced
2. A simple architecture or workflow diagram
3. Reproducible setup steps
4. Sanitized screenshots, logs, or command output
5. Security decisions, troubleshooting notes, and lessons learned

This profile is being rebuilt deliberately: older course exercises remain available as learning history, while completed security labs will become the primary portfolio.
